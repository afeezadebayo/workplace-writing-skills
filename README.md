Free **Agent Skills** (`SKILL.md`) that help Claude, Claude Code, OpenAI Codex and other AI agents write workplace documents people actually read and act on: memos, proposals, reports, executive summaries, SOPs, policies, project briefs and more. They work in stages, put the main point first and test drafts with a fresh reader.

## Install

```bash
git clone https://github.com/afeezadebayo/workplace-writing-skills.git
# Claude Code
cp -r workplace-writing-skills/memos-one-pagers ~/.claude/skills/
# Codex and other agents
cp -r workplace-writing-skills/memos-one-pagers ~/.agents/skills/
```

In Claude.ai or Claude Desktop, zip a single skill folder and upload it under **Settings → Capabilities → Skills**.

Then ask your agent, for example: *"Write a one-page decision memo for this"* or *"Rewrite this in plain English."*
